# Aircraft Maintenance Data – Airbus A320 (Graduation Project)

بيانات جاهزة لتطبيق صيانة طائرات Airbus A320: قاعدة بيانات للـ Backend + داتا معالجة لموديلات Machine Learning.

## الهيكل
```
db/                 a320_maintenance.db (SQLite جاهزة) · schema.sql (PK/FK/CHECK) · seed.py · queries.sql
data/raw/           الداتا الأصلية (NASA C-MAPSS حقيقي · FAA SDR حقيقي · أسطول A320 اصطناعي)
data/processed/     داتا جاهزة للتدريب (cmapss: مُطبَّعة + RUL · sdr: train/val/test · diagnosis: أعراض → عطل)
scripts/            build_synthetic.py (بيولّد الداتا الاصطناعية بشكل متسق وقابل للتكرار، seed=320)
ml/                 rul_baseline.py · sdr_classifier.py · diagnosis_classifier.py · diagnosis_model.json
DATA_SOURCES.md     المصادر والرخص وأي تحذيرات (اقرأه قبل ما تكتب التقرير)
```

## Backend
```bash
sqlite3 db/a320_maintenance.db < db/queries.sql    # أمثلة استعلامات لشاشات التطبيق والـ Dashboard
python scripts/build_synthetic.py                    # إعادة توليد الداتا الاصطناعية (اختياري)
python db/seed.py                                    # إعادة بناء القاعدة من الـ CSV (وبيتأكد من الـ foreign keys)
```
`db/schema.sql` متوافق تقريبًا مع PostgreSQL/MySQL (ممكن تحتاج تعديل بسيط في `PRAGMA` و`CHECK`).
الجداول:
- الأسطول: `aircraft, engines, technicians`
- الكتالوج المرجعي: `parts_inventory` (ATA code · function · interval · inspection checklist) · `symptoms` · `fault_catalog` (ATA · القطعة المرجّحة · recommended checks) · `fault_symptoms`
- سجلات الصيانة: `maintenance_schedule` · `component_status` (آخر صيانة / الموعد الجاي / الحالة لكل قطعة في كل طيارة) · `defect_reports` · `defect_symptoms` · `work_orders` · `engine_sensor_data`
- بلاغات حقيقية: `faa_sdr_reports`

ربط الجداول بـ data model التطبيق:
| التطبيق | الجداول |
|---|---|
| `AircraftPart` (ataCode, name, system, function, maintenanceInterval, lastServiced, status, checklist) | `parts_inventory` + `component_status` |
| `SymptomEntry` | `symptoms` |
| `DiagnosisResult` (faultName, ataCode, confidence, recommendedChecks, severity) | `fault_catalog` + نتيجة `ml/diagnosis_model.json` |

الـ checklists والـ recommended checks مكتوبة بصيغة عامة للتوضيح، **مش منقولة من AMM/TSM بتوع Airbus** ومينفعش تُستخدم في صيانة حقيقية.

## Machine Learning
```bash
pip install -r requirements.txt
python ml/rul_baseline.py FD001        # توقع العمر المتبقي للمحرك (FD001..FD004)
python ml/sdr_classifier.py hazard_binary   # تصنيف بلاغات الأعطال (أو hazard_category)
python ml/diagnosis_classifier.py           # تشخيص العطل من الأعراض + تصدير diagnosis_model.json
```
| المهمة | الداتا | Baseline |
|---|---|---|
| توقع RUL | NASA C-MAPSS | RMSE 15.5–19.9 (RUL مقصوص عند 125) |
| تصنيف خطورة البلاغ (Yes/No) | FAA SDR | Macro-F1 ≈ 0.76 |
| تصنيف نوع البلاغ (16 فئة) | FAA SDR | Accuracy ≈ 0.88 / Macro-F1 ≈ 0.60 (الفئات غير متوازنة: التآكل 72%) |
| تشخيص العطل من الأعراض (31 عطل) | Synthetic A320 | Naive Bayes: Accuracy ≈ 0.96 / Top-3 = 1.00 |

> نتيجة التشخيص عالية لأن الداتا الاصطناعية متولّدة من نفس قواعد الربط (عَرَض → عطل) مع ضوضاء بسيطة. الرقم ده بيثبت إن الـ pipeline شغّال، **مش** إن الموديل هيدّي نفس الدقة على داتا تشغيل حقيقية.

### تشغيل موديل التشخيص من غير Python (مثلًا Laravel)
`ml/diagnosis_model.json` فيه بارامترات Bernoulli Naive Bayes. لكل عطل `f`:
`score(f) = class_log_prior[f] + Σ_s (x_s ? log_p[f][s] : log_1mp[f][s])` وبعدين `confidence = softmax(score)`،
وتجيب الـ ATA والـ recommended checks من `fault_catalog`.

> ملاحظة: داتا `data/raw/a320_synthetic` **اصطناعية**، وداتا C-MAPSS محاكاة لمحرك توربوفان عام (مش محرك A320 بالتحديد). التفاصيل في `DATA_SOURCES.md`.

## Direct access from Python (GitHub Raw)

Install pandas:

```bash
pip install pandas
```

Load the complete synthetic A320 tables:

```python
from data.load_remote_data import load_a320_data

tables = load_a320_data()
aircraft = tables["aircraft"]
sensor_data = tables["engine_sensor_data"]
defects = tables["defects"]
work_orders = tables["work_orders"]
```

Load a NASA C-MAPSS compressed file:

```python
from data.load_remote_data import load_nasa_cmapss
fd001 = load_nasa_cmapss("train", "FD001")
```

Raw URL pattern:
`https://raw.githubusercontent.com/Agjfh/aircraft-maintenance-data/main/<path>`

**Data caveats:** A320 fleet and maintenance records are synthetic (generated by `scripts/build_synthetic.py`), C-MAPSS is a general turbofan simulation (not A320-specific), and the `a320_extra` flight-operations file is marked unverified. Consult `DATA_SOURCES.md` before citing or using the datasets.
